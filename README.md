# 💨 Telegram AI Vape Store & Admin Dashboard
### ჭკვიანი გაყიდვების ასისტენტი Gemini 3.8 Flash-ზე და მართვის პანელი (Web & Mini App)

ეს არის სრულფასოვანი ელექტრონული კომერციის სისტემა ტელეგრამში ვეიპის სითხეების (E-Liquids) რეალიზაციისთვის. სისტემა იყენებს **Google Gemini 3.8 Flash**-ის ხელოვნურ ინტელექტს მომხმარებლებთან საკომუნიკაციოდ, ავტომატურად ამუშავებს შეკვეთებს, უსმენს ტელეგრამ ჩანელს ახალი პროდუქციის ავტო-დასამატებლად და გააჩნია თანამედროვე სამართავი პანელი (Admin Dashboard) როგორც ბრაუზერისთვის, ისე პირდაპირ ტელეგრამის Mini App-ის სახით.

## 🌟 ძირითადი ფუნქციები

1. **🤖 Gemini 3.8 Flash AI ასისტენტი (DM ჩატში):**
   - **მრავალენოვანი:** ავტომატურად ამოიცნობს მომხმარებლის ენას (ქართული, ინგლისური, რუსული) და პასუხობს იმავე ენაზე.
   - **ტონალობა:** საქმიანი, თავაზიანი და მსუბუქი იუმორით.
   - **ანტი-ჰალუცინაცია:** იცნობს რეალურ კატალოგს, ფასებს, VG/PG თანაფარდობას, ნიკოტინის დონეს (20mg, 50mg, 0mg) და მარაგებს. არ იგონებს არარსებულ პროდუქტებს.
   - **მარაგის ამოწურვისას (Fallback):** სთავაზობს მსგავს გემოებს, იწერს კონტაქტს ან გადაამისამართებს ოპერატორთან.

2. **📢 ტელეგრამ ჩანელის ავტო-სინქრონიზაცია:**
   - როდესაც ჩანელში დებთ ახალ პოსტს პროდუქტის შესახებ, ბოტი Gemini-ს მეშვეობით **ავტომატურად ამოიკითხავს** არომატს, ფასს, VG/PG-ს, ნიკოტინს, მოცულობას და ამატებს ბაზაში ჩანელის პოსტის ბმულთან ერთად!

3. **🛒 შეკვეთის გაფორმების სრული პროცესი (FSM):**
   - **მიწოდება:** კურიერით მიტანა, თვითგატანა (Pickup) ან ფოსტა.
   - **ლოკაცია:** მომხმარებელს შეუძლია გააზიაროს ტელეგრამის ოფიციალური GPS ლოკაცია რუკაზე ან ჩაწეროს მისამართი. თვითგატანისას ბოტი აწვდის მაღაზიის ზუსტ მისამართსა და კოორდინატებს.
   - **ტელეფონის ნომერი:** ოფიციალური `Share Contact` ღილაკი + სხვა ნომრის ჩაწერის ალტერნატივა.
   - **გადახდა:** საბანკო გადარიცხვა (ბანკის რეკვიზიტების ჩვენებით) ან ნაღდი ანგარიშსწორება ადგილზე.

   - მყისიერი ალერტი ადმინისტრატორის პირად ტელეგრამზე.
   - რეალურ დროში შეტყობინება ადმინ-პანელში (ხმოვანი სიგნალით & Toast შეტყობინებით).
   - ელ-ფოსტის გაგზავნა (Email Alert).

5. **💬 Live Chat & Human Handoff (ადამიანის ჩართვა):**
   - ადმინს პანელში რეალურ დროში შეუძლია თვალი ადევნოს კლიენტისა და AI-ს მიმოწერას.
   - ნებისმიერ მომენტში შეუძლია დააჭიროს **"⏸ ბოტის დაპაუზება"** და თავად გააგრძელოს კლიენტთან საუბარი პანელიდან პირდაპირ ტელეგრამში.

   - ტელეგრამშივე ჩაშენებული Mini App (WebApp), რათა ტელეფონიდან მართოთ მაღაზია.

7. **📢 მარკეტინგი და ლოიალობა:**

## 🚀 სწრაფი დაწყების ინსტრუქცია (Local Setup)

### ნაბიჯი 1: პარამეტრების კონფიგურაცია (`.env`)
გახსენით ფაილი `.env` და შეავსეთ შემდეგი ველები:

```env
# ტელეგრამ ბოტის ტოკენი (@BotFather)
TELEGRAM_BOT_TOKEN=7123456789:AAHxxxxxxxxx

# ტელეგრამ ჩანელის Username ან ID (სადაც პოსტები იდება)
TELEGRAM_CHANNEL_ID=@your_vape_channel

# თქვენი პირადი Telegram ID (გაიგეთ @userinfobot-ისგან)
ADMIN_TELEGRAM_IDS=12345678

# Google Gemini API Key (Google AI Studio ან Google Cloud)
GEMINI_API_KEY=AIzaSyxxxxxxxxxxxxxxxxx
GEMINI_MODEL=gemini-3.8-flash
```

> [!NOTE]
> **როგორ ჩავრთოთ ჩანელის ავტო-მოსმენა?**
> დაამატეთ თქვენი ბოტი თქვენს ტელეგრამ ჩანელში **ადმინისტრატორად** (Administrator) პოსტების წაკითხვის უფლებით.

### ნაბიჯი 2: სატესტო პროდუქტების დამატება (Seeding)
გაუშვით წინასწარ გამზადებული სკრიპტი, რომელიც ბაზაში ჩატვირთავს 10 პოპულარულ ვეიპის სითხეს:

```bash
python seed_data.py
```

### ნაბიჯი 3: პროექტის გაშვება
გაუშვით სერვერი და ბოტი ერთი ბრძანებით:

```bash
python run.py
```

გაშვების შემდეგ:
- **ვებ-პანელი:** გახსენით ბრაუზერში: [http://localhost:8000/admin](http://localhost:8000/admin)
- **ავტორიზაცია:**
  - მომხმარებელი: `admin`
  - პაროლი: `admin123`
- **ტელეგრამ ბოტი:** გახსენით თქვენი ბოტი ტელეგრამში და დააჭირეთ `/start`.

## 📱 როგორ ჩავრთოთ Telegram Mini App ბოტში?

1. გადადით ტელეგრამში ბოტთან `@BotFather`.
2. გაგზავნეთ ბრძანება `/mybots` და აირჩიეთ თქვენი ბოტი.
3. გადადით: `Bot Settings` -> `Menu Button` -> `Configure menu button`.
4. გაუგზავნეთ თქვენი ადმინ-პანელის მისამართი (მაგ: `https://your-domain.com/admin` ან Ngrok/Cloud Run ლინკი).
5. ღილაკის სახელად მიუთითეთ: `📱 მართვის პანელი`.
6. ახლა ბოტში მარცხენა ქვედა კუთხეში გამოჩნდება მენიუს ღილაკი, რომელზე დაჭერითაც პირდაპირ ტელეგრამში გაიხსნება სამართავი პანელი!

## ☁️ Google Cloud-ში (Cloud Run) გაშვება (300$ კრედიტებით)

სისტემა სრულად კონტეინერიზებულია `Dockerfile`-ით და მზადაა Google Cloud Run-ზე გასაშვებად:

1. **დააინსტალირეთ Google Cloud SDK (`gcloud`):**
   ```bash
   gcloud auth login
   gcloud config set project YOUR_PROJECT_ID
   ```

2. **დააბილდეთ და გაუშვით Cloud Run-ზე:**
   ```bash
   gcloud run deploy vape-store-bot \
     --source . \
     --platform managed \
     --region europe-west1 \
     --allow-unauthenticated \
     --set-env-vars TELEGRAM_BOT_TOKEN="თქვენი_ტოკენი",GEMINI_API_KEY="თქვენი_api_key",ADMIN_TELEGRAM_IDS="თქვენი_id"
   ```

Cloud Run მოგცემთ უსაფრთხო HTTPS მისამართს (მაგ: `https://vape-store-bot-xxxxx.a.run.app`), რომელიც შეგიძლიათ გამოიყენოთ ვებ-პანელისთვის და Telegram Mini App-ისთვის.
